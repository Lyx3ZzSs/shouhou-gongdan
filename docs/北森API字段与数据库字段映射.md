## 15. `serviceCycleStart__c` — 周期服务开始时间

| 项目               | 内容                                                                         |
| ------------------ | ---------------------------------------------------------------------------- |
| **含义**     | 周期服务的开始时间                                                           |
| **示例值**   | `1784797500`（秒级时间戳）                                                 |
| **目标表**   | `project_info.service_start_time`（DateTime）                              |
| **转换规则** | `datetime.fromtimestamp(1784797500)` → `2026-07-28 12:05:00`            |
| **备注**     | 北森 API 传入的是秒级 Unix 时间戳，写入 PG 的`timestamp without time zone` |

---
