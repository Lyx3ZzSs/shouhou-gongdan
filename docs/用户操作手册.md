## 快速入门

### 打开工作台

在浏览器中访问 `http://localhost:5173`（开发环境）或生产环境地址，登录后进入工作台。

### 典型审核流程

```
选择工单 → 逐字段审核 → 修改有误字段 → 确认无误字段 → 提交审核 → 进入下一条
```

## 界面概览

工作台采用**三栏布局**，从左到右依次为：

```
┌────────────┬──────────────────────────┬──────────────┐
│            │                        │              │
│  工单队列   │      字段审核区         │  审核控制台   │
│  (左侧)    │      (中间)            │  (右侧)      │
│            │                        │ 默认折叠      │
└────────────┴──────────────────────────┴──────────────┘
                              │ 决策栏（底部固定）
```

| 区域 | 宽度 | 说明 |
|------|------|------|
| 工单队列 | 300px，可收起 | 待审核工单列表，点击切换工单 |
| 字段审核区 | 自适应 | 核心工作区，逐字段审核和修改 |
| 审核控制台 | 340px，默认折叠 | 审核进度、变更记录、备注 |
| 决策栏 | 底部固定 | 导航按钮 + 审核结论按钮 |

点击左侧栏顶部的 <kbd>☰</kbd> 按钮可展开/收起队列，点击右侧栏顶部的 <kbd>☰</kbd> 按钮可展开/收起控制台。

## 工单队列

### 切换工单

在左侧队列面板中点击任意工单行，即可加载到中间审核区。

### 队列信息

每个工单卡片显示：
- **工单编号** — 系统生成的唯一编号
- **站点名称** — 问题所在站点
- **客户名称** — 报修客户
- **创建时间** — 工单创建时间
- **风险标签** — 高风险/中风险/低风险
- **异常数量** — 该工单存在的校验异常数
- **SLA 倒计时** — 距离超时的剩余时间

### 编辑锁

打开工单后，系统自动获取编辑锁，防止其他审核员同时编辑（锁 5 分钟自动释放，切换工单或关闭页面时自动释放）。其他审核员可以看到锁持有者信息。

## 审核工单

### 字段分组

工单字段按业务含义分为 8 组，点击组名可展开/收起：

| 分组 | 包含字段 |
|------|----------|
| 站点信息 | 站点名称、调度名称 |
| 项目信息 | 项目编号、项目名称、项目省份 |
| 客户信息 | 客户名称、客户等级 |
| 问题描述 | 问题描述、反馈渠道 |
| 产品信息 | 产品线、产品类别、产品型号 |
| 问题分类 | 一级/二级/三级问题分类、工单类型、问题类型、故障类别、故障详情 |
| 责任归属 | 责任人、责任部门、主要部门、售后人员、转交人员、转交部门 |
| 工单等级 | 工单等级、故障等级、现场等级、要求解决时间 |

### 字段状态

每个字段有四种可能状态：

| 状态 | 图标 | 说明 |
|------|------|------|
| **待审核** | 无标记 | 尚未审核 |
| **已确认** | ✓ 绿色 | 已确认字段值无误 |
| **已修改** | 铅笔图标 | 字段值已被修改 |
| **校验异常** | ⚠ 黄色/🔴 红色 | 系统检测到问题 |

### 字段行布局

```
┃ ▌ 字段名* 🔑 ?  │  原值 → 现值  │  置信度  │  状态标签  │  操作按钮(悬停显示)
```

- **左侧色条**：红色 = 阻断级异常，黄色 = 告警级异常，无色 = 正常
- **字段名后的 `*`**：必填字段
- **字段名后的 🔑**：关键字段（修改后影响较大）
- **字段名后的 ?**：用户标记为不确定

### 查看字段差异

已修改的字段以 **diff 对比视图** 展示：

```
原值（删除线灰色） → 现值（高亮底色）
```

光标悬停在某一行时，操作按钮才会出现，减少视觉干扰。

### 编辑字段

1. 悬停在目标字段行上
2. 点击 **✏️ 编辑** 按钮
3. 弹出编辑区，上方显示原值供参考
4. 输入新值，选择修改原因（共 7 种预设原因）
5. 回车确认编辑，`Esc` 取消

字段修改后，状态自动变为"已修改"，变更会记录到右侧控制台的"当前变更"列表中。

### 确认字段

- 单字段确认：悬停 → 点击 **✓ 确认** 按钮
- 批量确认：在分组标题栏点击 **本组全部确认**，一键确认该组所有未修改字段

### 使用系统建议值

当 AI 系统对该字段有建议值时，行内会出现 💡 灯泡图标，点击可使用系统建议值替换当前值。

### 重置字段

对于已修改但想撤回的字段，点击 **↺ 重置** 按钮恢复为系统原始值。

### 标记不确定

对于值存疑但无法确定的字段，点击 **··· 更多 → 标记为不确定**，该字段会显示 `?` 标记，提醒后续复核。

### 添加字段备注

点击 **··· 更多 → 添加字段备注**，可为任意字段添加审核备注文字。

### 查看修改历史

点击 **··· 更多 → 查看修改历史**，可查看该字段的所有历史变更记录（含修改人、时间、前后值 diff）。

## 提交审核结论

### 决策栏按钮

底部固定栏从左到右：

| 按钮 | 快捷键 | 说明 |
|------|--------|------|
| ◀ 上一条 | `J` | 切换到队列中上一条工单 |
| 下一条 ▶ | `K` | 切换到队列中下一条工单 |
| 暂存 | `Cmd+S` / `Ctrl+S` | 保存当前审核进度为草稿 |
| 退回补充 | — | 退回给 AI 重新生成，需填写退回原因 |
| 驳回 | — | 驳回工单，需填写驳回原因 |
| **提交审核 ✓** | `Cmd+Enter` | 提交审核结论（主 CTA） |
| 更多 ··· | — | 转交复核等次要操作 |

### 提交确认

点击"提交审核"后弹出确认对话框，显示：
- 字段变更摘要（修改数量和详情）
- 校验异常处理情况

系统自动判断审核类型：
- 无字段修改 → **直接通过**
- 有字段修改 → **修改后通过**

勾选"提交后进入下一条工单"可连续审核（默认不勾选，提交后停留在当前工单查看结果）。

### 版本冲突

如果提交时检测到工单已被他人修改（版本号不一致），会弹出冲突提示，建议刷新后重新审核。

## 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| `J` | 上一条工单 |
| `K` | 下一条工单 |
| `Cmd/Ctrl + Enter` | 提交审核 |
| `Cmd/Ctrl + S` | 暂存草稿 |
| `Alt + ↓` | 跳到下一个异常字段 |
| `Esc` | 关闭弹窗/退出编辑 |

## 常见场景

### 场景 1：AI 生成的工单完全正确

1. 打开工单，逐字段确认无异常
2. 使用"本组全部确认"快速确认各分组
3. 点击 **提交审核**，系统自动识别为"直接通过"

### 场景 2：部分字段需要修改

1. 打开工单，定位到需要修改的字段
2. 编辑字段值，选择修改原因
3. 确认其余无误字段
4. 点击 **提交审核**，系统自动识别为"修改后通过"
5. 修改的字段自动入库为 Bad Case，用于 AI 模型优化

### 场景 3：工单存在校验异常

1. 注意行左侧的红色/黄色色条标识
2. 点击工具栏的"只看异常字段"筛选异常
3. 使用 `Alt + ↓` 逐个跳转处理异常
4. 处理完毕后提交审核

### 场景 4：工单质量较差需要退回

1. 点击 **退回补充** 按钮
2. 在弹窗中填写退回原因（如"问题描述不清晰"）
3. 提交后退回 AI 重新生成

### 场景 5：暂存继续

1. 审核过程中需要中断
2. 按 `Cmd+S` 暂存当前进度
3. 下次打开该工单时自动恢复暂存状态

## 常见问题

### Q: 为什么我的编辑按钮点不了？

A: 请检查：
1. 该字段是否为只读字段（灰色显示）
2. 是否有其他审核员正在编辑该工单（检查编辑锁持有人）
3. 网络连接是否正常

### Q: 提交时提示"版本冲突"怎么办？

A: 说明在你审核期间，该工单已被其他人修改。请刷新页面获取最新版本，重新审核。

### Q: 编辑锁什么时候释放？

A: 以下情况会自动释放：
- 提交审核结论后
- 切换工单时
- 关闭浏览器标签页时
- 5 分钟无操作后自动过期

### Q: 如何切换到紧凑模式？

A: 点击工具栏最右侧的 <kbd>⊟</kbd> 按钮，行高和间距会缩小，适合高密度审核场景。再次点击恢复标准模式。

### Q: 右侧控制台如何打开？

A: 默认折叠以减少视觉干扰。点击右侧的竖条窄轨道或 <kbd>☰</kbd> 按钮展开。

### Q: 支持移动端审核吗？

A: 工作台支持响应式布局。在屏幕宽度 < 1024px 时，队列和侧栏变为覆盖层，主审核区自适应展示。
