# AI 售后工单审核平台 — 用户操作手册

## 1. 页面入口

桌面端左侧导航包含：概览、开始审核、稍后处理、工单搜索、审核统计；管理员还可进入同步失败。系统面向 1280–1920px 桌面浏览器，不设计独立手机审核流程。

## 2. 标准审核流程

```text
概览 → 开始审核 → 系统领取下一张 → 核对材料与六个关键字段 → 通过/驳回 → 下一张
```

系统按创建时间领取首张未被其他审核员锁定的工单。打开后自动获取 Redis 编辑锁并持续续期；锁丢失或版本冲突时禁止提交，刷新后重新审核。

## 3. 六个可编辑字段

| 字段 | 操作说明 |
|---|---|
| 场站编号 | 从候选场站选择后自动带出项目名称 |
| 项目名称 | 可在联动结果基础上修正 |
| 问题责任人 | 从北森员工候选项选择，自动带出责任部门 |
| 反馈人姓名 | 可选 |
| 反馈人联系方式 | 可选；填写时必须为 11 位手机号 |
| 工单描述 | 可补充故障现象、时间和影响范围 |

其他字段只读展示。修改后显示 AI 原值与人工最终值，提交时记录最终 Diff。

## 4. 核对材料与阻断问题

点击“查看核对材料”，可集中查看原始客服对话、附件和客户/项目台账。

阻断问题会显示在关键字段下方：

- 属于六个关键字段：修改正确后即可解除阻断。
- 属于其他只读字段或缺少来源数据：点击“驳回上游补充”，系统自动带入原因并打开驳回确认。

存在未解决阻断问题时不能审核通过。

## 5. 跳过、暂存与关闭

- “暂存并跳过”保存当前修改，释放编辑锁，并把工单放入“稍后处理”。
- 从“稍后处理”点击“继续审核”会恢复草稿并重新获取锁。
- 关闭有修改的审核抽屉时，必须明确选择“放弃修改”或“暂存并跳过”；关闭本身不会误存草稿。

## 6. 提交与查询

- 无修改可直接审核通过。
- 有修改时确认最终 Diff 后提交。
- 驳回必须填写原因。
- 工单搜索覆盖已通过和已驳回工单，只读详情展示最终值、审核人、审核时间和 Diff。

审核成功后立即返回，不等待销售易同步。

## 7. 同步失败处理（管理员）

- `failed`：查看原因后可人工重试。
- `uncertain`：先到销售易核实。若已创建，输入销售易工单号完成对账；若未创建，确认后转为可重试状态。
- 每次人工重试和对账都会写入审计日志。

## 8. 常见问题

**为什么不能提交？** 先检查阻断问题、必填字段、手机号格式和编辑锁状态。

**为什么工单只读？** 工单可能已审核，或编辑锁被其他审核员持有。

**关闭后修改为什么不见了？** 选择“放弃修改”会删除草稿；需要保留时应选择“暂存并跳过”。

**页面提示数据库或缓存不可用怎么办？** 管理员访问 `/ready` 检查 PostgreSQL 与 Redis；任一依赖异常都会返回 503。
